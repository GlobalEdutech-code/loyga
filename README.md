# ลอย · Loy Krathong Coding

เว็บ HTML/CSS/JavaScript หน้าเดียวสำหรับวาดกระทงและต่อบล็อก Blockly พร้อมใช้งานบน GitHub Pages ไม่มี backend และไม่ต้องติดตั้ง npm

## ใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือรันเว็บด้วย `python -m http.server 8080` แล้วเปิด `http://localhost:8080` (แนะนำวิธีนี้เพื่อให้การบันทึกมี origin ที่แน่นอน)

1. วาดกระทง เลือกสี/ขนาด ใช้ยางลบ ย้อนกลับ หรือล้างภาพได้
2. กด **Add Krathong** เพื่อสร้างกระทงใหม่ คลิกกระทงในแม่น้ำหรือชื่อด้านล่างเพื่อเลือก
3. ลากบล็อกมาต่อใต้ **when run** แต่ละกระทงเก็บโปรแกรมของตัวเอง
4. **Run** ทดลองโปรแกรม, **Float** เริ่มล่องอัตโนมัติ, **Stop** หยุดกระทงที่เลือก, **Reset** คืนตำแหน่งก่อน Run/Float ครั้งแรกของรอบนั้น
5. **Save** บันทึกทันที, **Export/Import** สำรองหรือย้ายโปรเจกต์ Import จะใช้โปรเจกต์ในไฟล์แทนโปรเจกต์ปัจจุบัน ควร Export งานเดิมก่อน

กระทงหลายใบเคลื่อนไหวพร้อมกันได้ คำสั่งหมุนหน่วยองศา, move หน่วยพิกเซล, wait หน่วยวินาที กระทงเริ่มหันขวา เมื่อออกนอกขอบทั้งใบจะกลับเข้าฝั่งตรงข้าม

## ขึ้น GitHub Pages

อัปโหลด `index.html`, `style.css`, `app.js`, `.nojekyll` และโฟลเดอร์ `vendor/` ทั้งหมดไว้ที่ราก repository จากนั้นไปที่ **Settings → Pages → Deploy from a branch → main → / (root) → Save** ไม่ต้องรัน build และใช้ได้กับ repository ที่มีชื่อ path ใดก็ได้ เพราะอ้างอิงไฟล์แบบ relative

หรือแตก `loy-krathong-github-pages.zip` แล้วอัปโหลดไฟล์ข้างใน (ไม่ใช่ ZIP) ไปยัง repository

## ตรวจสอบและสร้างโฟลเดอร์พร้อมเผยแพร่

`node build.cjs`

ตรวจ syntax, DOM IDs และพฤติกรรม runner/wrap โดยใช้ Node.js มาตรฐาน แล้วคัดลอกเว็บไป `dist/` ไม่ต้องใช้ dependency สำหรับ build

## ข้อจำกัด

- บันทึกอัตโนมัติใน localStorage ของเบราว์เซอร์/origin นี้เท่านั้น GitHub Pages ไม่ได้ซิงก์งานข้ามอุปกรณ์ การล้างข้อมูลเว็บจะลบงานด้วย
- โหลดกลับมาในสถานะหยุด กด Run หรือ Float เพื่อเริ่มใหม่ จุด Reset และประวัติ Undo อยู่เฉพาะรอบที่เปิดเว็บ
- ขณะเคลื่อนไหวบันทึกตำแหน่งทุก 4 วินาที จำกัด 100 กระทง, Undo 25 ขั้น, Import 25 MB และความจุจริงขึ้นกับ localStorage ของเบราว์เซอร์
- Blockly 12.3.1 รวมไว้ใน vendor ไม่ต้องโหลด CDN; Save/Import/Export ใช้งานได้โดยไม่ใช้เครือข่ายเมื่อเปิดหน้าเว็บและไฟล์ที่จำเป็นได้ เว็บนี้ไม่ได้ติดตั้ง service worker สำหรับรับรองการเปิด GitHub Pages แบบ offline
- ไม่มีบัญชีผู้ใช้ แกลเลอรีออนไลน์ หรือ backend
- ใช้ safe interpreter ไม่ใช้ eval/new Function ประมวลผลโปรแกรมจากผู้ใช้

## นำเข้า PNG และบล็อกทิศทาง
กด Import PNG เพื่อนำภาพเข้าแทนภาพบนพื้นที่วาด โดยรักษาสัดส่วนและความโปร่งใส วาดต่อหรือ Undo ได้ แล้วกด Add Krathong เพื่อเพิ่มลงแม่น้ำ (PNG สูงสุด 10 MB / 40 ล้านพิกเซล)
บล็อก move up / left / right / down เคลื่อนตามทิศของหน้าจอ ไม่ขึ้นกับมุมกระทง ส่วน move เดิมเคลื่อนตามมุมหันของกระทง


บล็อก set speed กำหนดความเร็วคำสั่ง move ทุกทิศของกระทงนั้นเป็น steps/second (1–2000, ค่าเริ่มต้น 95) มีผลกับคำสั่งถัดไป บันทึกแยกแต่ละกระทง ไม่เปลี่ยนความเร็วหมุน/เวลารอ/กระแสน้ำ Float เมื่อพ้นขอบบนทั้งใบจะวนกลับเข้าจากขอบล่าง และกลับกัน


ลากกระทงบนแม่น้ำได้ด้วยเมาส์หรือสัมผัส การจับกระทงจะหยุดโปรแกรมและ Float ของใบนั้น วางแล้วกด Run/Float เพื่อเริ่มใหม่ ตำแหน่งที่วางเป็นจุดเริ่มรอบใหม่
Add เทียน: กดปุ่มแล้วแตะบนภาพตรงฐานเทียน เพิ่มได้หลายเล่ม พร้อมเปลวไฟและแสงเรืองที่รวมในภาพโปร่งใส ใช้ Undo/ยางลบได้ กด Draw เพื่อกลับไปวาด แสงเทียนเป็นส่วนหนึ่งของภาพ ไม่ใช่เปลวไฟเคลื่อนไหว


ลบกระทง: เลือกกระทงแล้วกด ลบกระทง ในแถบควบคุม ลบรูปและโปรแกรมของใบนั้นพร้อมหยุดการเคลื่อนไหว และบันทึกทันที ภาพในพื้นที่วาดยังอยู่ การลบไม่มี Undo ควร Export ก่อนหากต้องการสำรอง
