# ลอย · Loy Krathong Coding

เว็บ HTML/CSS/JavaScript สำหรับวาดกระทง ต่อ Blockly และลอยในแม่น้ำ รองรับ GitHub Pages และแม่น้ำร่วมกันผ่าน Supabase (ต้องตั้งค่าก่อน)

## ใช้งาน

เปิด index.html หรือรัน `python -m http.server 8080` แล้วเข้า http://localhost:8080 แนะนำ HTTP สำหรับการบันทึกและโหมดออนไลน์

- วาด เลือกสี/ขนาด ยางลบ Undo และ Clear
- Import PNG แทนภาพในพื้นที่วาด รักษาสัดส่วน/โปร่งใส วาดต่อได้ (สูงสุด 10 MB / 40 ล้านพิกเซล)
- Add เทียน แล้วแตะฐานเทียนบนภาพ แสงเรืองรวมในภาพ ใช้ Undo ได้ กด Draw เพื่อวาดต่อ
- Add Krathong เพิ่มลงแม่น้ำ แต่ละใบเก็บภาพและโปรแกรมแยกกัน
- ต่อบล็อกใต้ when run: move, move up/left/right/down, turn, wait, repeat, forever, set speed (1–2000 steps/วินาที)
- Run ทดลอง, Stop หยุด, Reset คืนจุดเริ่ม, Float ปล่อยลอยและเผยแพร่เมื่อเปิดโหมดออนไลน์
- ลากกระทงตัวเองเพื่อย้ายตำแหน่ง จะหยุดการเคลื่อนไหวและตั้งจุดเริ่มใหม่ กด Run/Float เพื่อเริ่มอีกครั้ง
- ลบกระทงลบใบที่เลือกและโปรแกรม ภาพในพื้นที่วาดยังอยู่ ไม่มี Undo สำหรับการลบ
- Save บันทึกในเครื่อง, Export/Import สำรองและย้ายโปรเจกต์ Import แทนงานในเครื่อง ควร Export ก่อน

## แม่น้ำร่วมกัน

อ่าน [SHARED-RIVER-SETUP.md](SHARED-RIVER-SETUP.md) สร้าง Supabase รัน supabase-setup.sql และกรอก cloud-config.js ด้วย Project URL + publishable/anon key

ยังไม่กรอก config = ใช้ในเครื่อง ไม่ซิงก์จริง เมื่อตั้งค่าครบ กด Float เพื่อแชร์ คนอื่นเห็นภายในประมาณ 5 วินาที กระทงคนอื่นดูได้แต่แก้ไม่ได้ สิทธิ์เจ้าของผูกกับเบราว์เซอร์ ไม่ใช่บัญชีข้ามเครื่อง Blockly/ภาพวาดต้นฉบับยังเก็บในเครื่อง

## GitHub Pages

แตก ZIP แล้วอัปโหลดไฟล์ข้างในรวม vendor/ และ cloud ทั้งสองไฟล์ลง repository ตั้ง Settings → Pages → Deploy from a branch → main → / (root) ไม่ต้อง build หรือ npm

## ตรวจและสร้างเว็บ

`node build.cjs`

ตรวจ syntax, DOM IDs, runner, ความเร็วและวนขอบ รวมทั้ง mock ของ cloud แล้วสร้าง dist/ การทดสอบ mock ไม่แทนการทดสอบ Supabase จริงหรือสองเบราว์เซอร์

## ข้อจำกัด

localStorage เก็บเฉพาะเบราว์เซอร์/origin เดิม ควร Export สำรอง โหลดกลับมาในสถานะหยุด จำกัดงานในเครื่อง 100 กระทง, Undo 25 ขั้น, Import JSON 25 MB ตำแหน่งขณะเคลื่อนบันทึกทุก 4 วินาที

โหมดออนไลน์ต้องมีอินเทอร์เน็ตและ Supabase ที่ตั้งค่าครบ ไม่มีการซิงก์ Blockly ข้ามเครื่อง ไม่มีบัญชีถาวรหรือ moderation ในรุ่นนี้ ดูคู่มือตั้งค่าเพิ่มเติม

Blockly 12.3.1 (Apache-2.0) และ Supabase JS 2.49.8 (MIT) รวมใน vendor/ พร้อมใบอนุญาต ไม่ต้องโหลด CDN

อัปเดต: กระทงที่โหลดจากงานเดิมหรือ Import จะลอยอัตโนมัติในเครื่อง (ยังไม่เผยแพร่ใบใหม่จนกด Float) กระทงสาธารณะลอยอัตโนมัติบนเครื่องผู้ชมด้วย ผู้สร้างกด Stop เพื่อหยุดใบของตัวเองได้ แต่ผู้ชมยังแสดงการลอยอัตโนมัติ Reset คืนตำแหน่งตอนโหลด
